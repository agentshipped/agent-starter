# agent-starter

Rules for any agent working in this repo.

1. Ask before inventing: if an API shape, file location or naming convention is not in the code,
   stop and ask. Do not guess.
2. One change, one commit, one test. A change without a test is a draft.
3. Never write secrets into files. Use `.env.example` with empty values.
4. Before claiming done: run the tests and paste the exact output.
